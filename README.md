# AI-Based Fake News Detection System

## Project Description
The AI-Based Fake News Detection System is a machine learning web application that analyzes news articles and predicts whether the given news is REAL or FAKE.

## Objectives
- Detect potentially fake news using machine learning.
- Convert news text into numerical features using TF-IDF.
- Classify news using Logistic Regression.
- Provide a simple web interface for users.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression

## Project Files
- `index.html` - Web interface
- `app.py` - Flask application
- `train_model.py` - Machine learning model training
- `news.csv` - News dataset
- `requirements.txt` - Required Python libraries
- `README.md` - Project documentation
